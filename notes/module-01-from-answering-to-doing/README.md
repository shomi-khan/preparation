## শেখার ফলাফল

এই module শেষে তুমি:
- LLM, chatbot, agent এবং agentic system-এর পার্থক্য ব্যাখ্যা করতে পারবে।
- Agent-এর perception, reasoning, action, learning, communication—এই subsystem-গুলোর ভূমিকা ও সীমাবদ্ধতা বুঝবে।
- Single agent নাকি multi-agent দরকার, trade-off দিয়ে সিদ্ধান্ত নিতে পারবে।
- Memory-এর ধরন ও context window-এর সীমা ব্যাখ্যা করতে পারবে।
- Lost in the Middle সমস্যাটি কী, কেন ঘটে এবং কীভাবে কমানো যায় তা বলতে পারবে।
