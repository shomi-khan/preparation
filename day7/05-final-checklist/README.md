# Final Preparation Checklist

এই checklist interview-এর আগে নিজের readiness যাচাই করার জন্য। সব box tick না হলেও interview দেওয়া যায়। গুরুত্বপূর্ণ হলো কোন বিষয়ে confident, কোন বিষয়ে partial understanding, আর কোন বিষয়ে hands-on gap আছে তা জানা।

## Python Fundamentals

- [ ] Data structure বেছে নেওয়ার কারণ ও complexity explain করতে পারি।
- [ ] Mutable/immutable, identity/equality এবং reference explain করতে পারি।
- [ ] Shallow/deep copy demonstrate করতে পারি।
- [ ] Iterator/generator implement করতে পারি।
- [ ] Decorator/context manager লিখতে পারি।
- [ ] Exception propagation ও custom exception handle করতে পারি।
- [ ] Type hints ও runtime validation-এর পার্থক্য explain করতে পারি।
- [ ] Async I/O concurrency ও event loop explain করতে পারি।
- [ ] Blocking call, cancellation ও timeout handle করতে পারি।

## Data, NumPy and Pandas

- [ ] Pandas দিয়ে dataset inspect ও clean করতে পারি।
- [ ] Missing value, duplicate ও outlier-এর policy justify করতে পারি।
- [ ] loc/iloc এবং groupby/merge ব্যবহার করতে পারি।
- [ ] Join cardinality ও row count validate করতে পারি।
- [ ] NumPy shape, dtype, vectorization ও broadcasting বুঝি।
- [ ] View বনাম copy test করতে পারি।
- [ ] Large dataset chunk/memory strategy explain করতে পারি।
- [ ] ML preprocessing-এ train/test leakage এড়াতে পারি।

## Machine Learning

- [ ] Supervised/unsupervised এবং classification/regression explain করতে পারি।
- [ ] Feature/label ও prediction time define করতে পারি।
- [ ] Train/validation/test split-এর কারণ explain করতে পারি।
- [ ] Stratified, group ও time-based split বেছে নিতে পারি।
- [ ] Baseline model train ও compare করতে পারি।
- [ ] Logistic Regression, Tree, Random Forest, KNN, SVM ও Boosting-এর intuition জানি।
- [ ] Overfitting, underfitting, bias/variance explain করতে পারি।
- [ ] Pipeline ও cross-validation ব্যবহার করতে পারি।
- [ ] Accuracy, precision, recall, F1, ROC-AUC ও PR-AUC বুঝি।
- [ ] Threshold ও calibration-এর পার্থক্য explain করতে পারি।
- [ ] Regression-এর MAE, RMSE ও R² ব্যাখ্যা করতে পারি।

## SQL

- [ ] JOIN, GROUP BY, HAVING ও CTE লিখতে পারি।
- [ ] Window function দিয়ে latest row/top-N per group বের করতে পারি।
- [ ] NULL semantics ও COUNT(*) বনাম COUNT(column) বুঝি।
- [ ] Duplicate join key-এর প্রভাব explain করতে পারি।
- [ ] Index ও EXPLAIN plan-এর basic বুঝি।
- [ ] Parameterized query ব্যবহার করতে পারি।
- [ ] Transaction/ACID-এর basic explain করতে পারি।
- [ ] Offset ও keyset pagination-এর trade-off জানি।

## LLM Fundamentals and Prompt Engineering

- [ ] Token, embedding, Transformer ও attention-এর intuition explain করতে পারি।
- [ ] Context window ও token budget estimate করতে পারি।
- [ ] Hallucination-এর কারণ ও mitigation explain করতে পারি।
- [ ] Prompting, RAG ও fine-tuning-এর পার্থক্য বুঝি।
- [ ] Zero-shot/few-shot prompt তৈরি করতে পারি।
- [ ] Structured output schema validate করতে পারি।
- [ ] Schema-valid কিন্তু incorrect response detect করতে পারি।
- [ ] Prompt injection ও indirect injection explain করতে পারি।
- [ ] Prompt/model versioned evaluation করতে পারি।

## RAG

- [ ] Ingestion ও query pipeline design করতে পারি।
- [ ] Parsing/chunking/metadata strategy justify করতে পারি।
- [ ] Embedding compatibility ও vector search explain করতে পারি।
- [ ] Hybrid search, reranking ও MMR-এর use case জানি।
- [ ] Recall@k, Precision@k, MRR ও nDCG বুঝি।
- [ ] Faithfulness ও correctness আলাদা করতে পারি।
- [ ] Citation correctness ও no-answer behavior test করতে পারি।
- [ ] Tenant ACL retrieval boundary-তে enforce করতে পারি।
- [ ] Document update/delete ও stale index lifecycle explain করতে পারি।

## Agents and Production AI

- [ ] Workflow ও agent-এর পার্থক্য explain করতে পারি।
- [ ] Tool calling cycle implement করতে পারি।
- [ ] Tool schema validation ও server-side authorization enforce করতে পারি।
- [ ] Agent loop-এর step/time/token budget রাখতে পারি।
- [ ] State/checkpoint ও safe resume explain করতে পারি।
- [ ] Human approval sensitive action-এর সঙ্গে bind করতে পারি।
- [ ] Retry, idempotency, rate limit ও circuit breaker explain করতে পারি।
- [ ] Logs, metrics ও traces-এর পার্থক্য জানি।
- [ ] Cost per successful task ও p95 latency measure করতে পারি।
- [ ] Dockerized service non-root user-এ চালাতে পারি।
- [ ] Secret runtime-এ inject করতে পারি।
- [ ] Canary/rollback ও incident response explain করতে পারি।

## Project Readiness

- [ ] অন্তত একটি project ৫-১০ মিনিটে explain করতে পারি।
- [ ] Architecture diagram আঁকতে পারি।
- [ ] নিজের actual contribution আলাদা করে বলতে পারি।
- [ ] Key design decision-এর alternative ও trade-off explain করতে পারি।
- [ ] Evaluation dataset, metrics ও sample size দেখাতে পারি।
- [ ] Known limitation ও failure mode বলতে পারি।

## Interview Readiness

- [ ] Technical answer ৬০-৯০ সেকেন্ডে explain করতে পারি।
- [ ] Definition-এর পরে mechanism ও example দিতে পারি।
- [ ] Trade-off ও limitation বলতে পারি।
- [ ] Unknown question-এ assumption পরিষ্কার করে structured reasoning দেখাতে পারি।
- [ ] Whiteboard-এ system design করতে পারি।
- [ ] নিজের resume-এর প্রতিটি claim defend করতে পারি।
- [ ] Behavioral answer-এ নিজের role ও outcome স্পষ্ট করতে পারি।

## Final Review Strategy

প্রতিটি domain-এর জন্য:
1. ৫টি question না দেখে explain করো।
2. ২টি ছোট code/query নিজে লেখো।
3. ১টি failure scenario debug করো।
4. ১টি design decision justify করো।
5. Weak topic list করে targeted revision করো।

~~~mermaid
flowchart TD
    A["Self-assessment"] --> B["Strong topics"]
    A --> C["Partial topics"]
    A --> D["Hands-on gaps"]
    B --> E["Quick revision"]
    C --> F["Explain + example practice"]
    D --> G["Build / test a small exercise"]
    E --> H["Mock interview"]
    F --> H
    G --> H
~~~

## Important

এই checklist-এর সব box tick না হলেও interview-এ অংশ নেওয়া যায়। যেসব বিষয়ে hands-on কাজ করোনি, সেগুলোকে production experience হিসেবে উপস্থাপন করবে না। নিজের প্রকৃত contribution, experiment, assumptions ও limitation পরিষ্কারভাবে বলবে।
